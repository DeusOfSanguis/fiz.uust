# Pacer Log

Небольшое приложение, которое превращает ссылки из Pacer в аккуратную таблицу:

1. принимает ссылку (или текст «поделиться») из приложения Pacer;
2. вытаскивает со страницы тренировки дату, километраж, время и прочие данные;
3. сохраняет записи в браузере;
4. по запросу отдаёт **Excel (.xlsx)** или CSV с колонками **дата · километраж · время · ссылка**.

Данные не уходят никуда, кроме самой страницы Pacer: всё считается в браузере.

---

## Быстрый старт

```bash
npm install
npm run dev        # http://localhost:5173
```

Сборка и запуск «по-взрослому» (со своим сервером-прокси):

```bash
npm run build
npm start          # http://localhost:4173
```

Тесты:

```bash
npm test
```

## Как этим пользоваться

1. В приложении Pacer откройте тренировку → **Поделиться** → **Скопировать ссылку**.
   Ссылка выглядит так: `https://share.mypacer.com/track/OXxdWKozfoIOzHAnr4OLFE`.
2. Вставьте её в поле «Добавить тренировку». Можно вставить сразу несколько ссылок — по одной в строке.
3. Приложение скачает страницу, разберёт её и покажет запись в списке.
4. Нажмите **Скачать Excel (.xlsx)** — получите файл со всеми записями.

Если ссылка не разобралась (Pacer изменил вёрстку, прокси не ответил), запись можно
добавить руками: кнопка **Вручную** — дата, километраж, время, ссылка.

### «Поделиться» с телефона

Приложение — PWA, и у него объявлен
[share target](https://developer.mozilla.org/en-US/docs/Web/Manifest/share_target):
после установки (Chrome → «Установить приложение») в системном меню «Поделиться»
появляется Pacer Log. Ссылка из Pacer уходит в приложение сама.

Требования: HTTPS (или localhost) и установленное приложение. В браузере без установки
работает обычная вставка из буфера — кнопка **Вставить**.

## Что попадает в таблицу

| Колонка | Пример | Примечание |
| --- | --- | --- |
| Дата и время | `20.10.2026 07:37` | настоящая дата Excel (`yyyy-mm-dd hh:mm`), а не текст |
| Километраж (км) | `6,80` | мили автоматически переводятся в километры |
| Время | `2:56:34` | настоящая длительность Excel `[h]:mm:ss` — суммируется; в блоке «Экспорт» можно переключить на минуты числом (`176,6`) |
| Ссылка | `https://share.mypacer.com/track/…` | исходная ссылка |

Формат колонки «Время» переключается в блоке «Экспорт»: длительность `2:56:34`
(по умолчанию) или десятичные минуты `176,6`.

Опционально (галочка в блоке «Экспорт») добавляются колонки **Активность**, **Шаги**,
**Калории**, **Набор высоты (м)**.

Дополнительно из страницы достаются автор, средний темп и каденс — они видны в интерфейсе
и сохраняются в резервной копии JSON.

CSV выгружается с `;` и BOM — Excel открывает его без «кракозябр» в русской и
нидерландской локали.

## Откуда берутся данные

Страница `share.mypacer.com/track/<id>` отдаётся уже с готовыми числами, поэтому парсер
работает по её тексту (HTML → текст), а не по хрупким CSS-селекторам. Поддерживаются
английские и русские подписи (`Time` / `Время`, `Distance` / `Дистанция`), метры и мили,
даты вида `Oct 20, 2026 7:37 AM`, `20.10.2026 19:41` и ISO.

Загрузка идёт по цепочке, пока какой-то источник не даст валидные данные:

1. **свой сервер** `/api/fetch` — быстро и без лимитов (есть в `npm run dev` и `npm start`);
2. **публичные CORS-прокси** (`corsfix`, `allorigins`, `codetabs`, `cors.lol`, `r.jina.ai`) —
   нужны, когда приложение открыто как статичный сайт: браузер не может запросить
   Pacer напрямую из-за CORS.

Если ни один источник не ответил, в интерфейсе видно, что именно пробовали и почему не вышло.

> **Важно.** Публичные прокси — чужие бесплатные сервисы: они могут тормозить, вводить
> лимиты и иногда лежать. Если планируете пользоваться приложением постоянно, запускайте
> его через `npm start` (или другой Node-хостинг) — тогда страницу скачивает ваш сервер,
> и сторонние сервисы не нужны.

## Хранение и приватность

- Записи лежат в `localStorage` браузера — без аккаунтов и серверной базы.
- Кнопка **Копия JSON** сохраняет резервную копию; ею же можно перенести данные на другое
  устройство (файл можно загрузить обратно — см. `src/lib/store.ts`, `setEntries`).
- Загружается только та страница Pacer, ссылку на которую вы вставили.

## Структура проекта

```
src/
  lib/pacer.ts     поиск ссылок, загрузка страницы, парсер
  lib/store.ts     записи в localStorage
  lib/xlsx.ts      генератор .xlsx (zip + OOXML, без зависимостей)
  lib/export.ts    состав колонок, xlsx/csv/json
  lib/format.ts    форматирование даты, времени, длительности
  components/      панель добавления, таблица, формы, экспорт, тосты
server.mjs         продакшн-сервер: статика + прокси к Pacer
tests/             парсер, загрузка, генерация Excel, UI (jsdom)
```

## Ограничения

- Если Pacer поменяет вёрстку страницы, парсер может перестать находить поля — тогда
  запись всё равно можно добавить вручную. Тесты на реальном HTML лежат в
  `tests/fixtures/`, их легко обновить.
- Время на странице Pacer отрисовывается в часовом поясе того, кто её открыл. Если
  страницу скачивает сторонний прокси, время суток может сместиться; дата при этом почти
  всегда верная. Свой сервер (`npm start`) отдаёт время так, как его увидели бы вы.
- Приложение однопользовательское и без синхронизации между устройствами.
